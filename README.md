# ALX Higher Level Programming

Ce dépôt contient les exercices du programme ALX portant sur la programmation de haut niveau : Shell, Emacs, Vi, JavaScript, et plus.

## Projets

- 0x00-0x02 : Shell, navigation, Emacs, Vi
- 0x12 : JavaScript - Warm up
- 0x13 : JavaScript - Objects, Scopes and Closures
